Project Overview

This project implements an 8-bit processor with two additional peripherals: a 16-bit Timer and a Watchdog Timer. The system is designed using Verilog HDL and verified through simulation and testing.

Processor Architecture

The processor consists of a program counter, instruction memory, instruction decoder, register file, ALU, control unit, data memory and I/O interface.

Additional Modules

16-bit Timer

Counts clock pulses using a 16-bit counter. Supports timer control, prescaling and timeout/interrupt status.

Watchdog Timer

Monitors processor operation. The CPU periodically sends a Kick signal. If timeout occurs, the watchdog requests a processor reset.
